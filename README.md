**PyWarp** is an innovative, high-throughput ETL (Extract, Transform, Load) engine designed to transform chaotic, unstructured operational logs into clean, enriched, and privacy-compliant data streams. 

It serves as a secure bridge between raw infrastructure telemetry and sophisticated downstream systems like AI/ML models, Security Information and Event Management (SIEM) platforms, and Observability dashboards.



## 🌐 Live Demo & Cloud Architecture

## ✨ Core Architecture & Design Philosophy

PyWarp tackles the significant challenge of processing massive volumes of diverse log data in Python by bypassing traditional constraints and implementing strict Data Quality (DQ) gates.

* **⚡ Hybrid Concurrency (Bypassing the GIL):** PyWarp combines `asyncio` for non-blocking I/O operations with a `multiprocessing.ProcessPoolExecutor` for CPU-bound tasks. This allows the engine to fully utilize multiple CPU cores in parallel for heavy regex string parsing and data transformation.
* **🧠 Zero-Latency SQL Enrichment:** Integrates an in-memory SQLite database (`knowdb`) for real-time lookups. It enriches raw logs with business context (e.g., department ownership, known threat levels) without introducing network latency.
* **🛡️ Type-Safe Topologies:** All data ingestion and routing configurations are defined using TOML files and validated at startup using **Pydantic**, preventing runtime errors in mission-critical pipelines.
* **🚑 Resilient Dead Letter Queues (DLQ):** Parsing failures are gracefully caught, tagged with `_error` metadata, and routed to designated Dead Letter Queues, ensuring zero data loss.

## 🔬 Enterprise Data Quality (DQ) Gates
Data is only as good as its accuracy. PyWarp goes beyond simple parsing by actively sanitizing the stream:
* **Deep PII Redaction:** Automatically detects and masks Credit Card numbers, passwords, and sensitive User IDs hidden within URL parameters to ensure strict PCI-DSS and GDPR compliance.
* **1NF Schema Normalization:** Splits squashed, malformed request strings into clean `http_method`, `endpoint`, and `protocol` columns.
* **Cryptographic Deduplication:** Uses a sliding window of MD5 hashes to detect and drop duplicate logs generated by malfunctioning routers.
* **Outlier & Typo Rejection:** Validates IP addresses using Python's `ipaddress` module and bounds-checks timestamps to prevent 1970/2099 epoch glitches.

## 🛠️ The CLI Tool Suite

PyWarp provides a command-line interface powered by `Typer`:
* `wparse daemon`: Initiates the continuous, high-performance ETL ingestion engine.
* `wproj init`: Scaffolds a structured project directory with boilerplate `topology/` and `conf/` files.
* `wpgen`: Blasts the engine with thousands of mock log events per second to stress-test your pipeline.
* `wprescue`: Recovers failed data from the Dead Letter Queue for re-ingestion.

## 🚀 Local Quick Start

### 1. Repository Setup
```bash
git clone [https://github.com/smreetyyadav37/pywarp.git](https://github.com/smreetyyadav37/pywarp.git)
cd pywarp
python -m venv venv
source venv/bin/activate  # Windows: .\venv\Scripts\activate
pip install -r requirements.txt
pip install -e .
```

### 2\. Launch the Web Interface
To interact with the engine visually and view live metrics:
```bash
streamlit run app.py
```

### 3\. Generate & Process Data (Via CLI)
To see PyWarp in action, open a terminal in your project root:
```bash
# Generate 500 fresh, simulated logs into data/in_dat/gen.dat
wpgen --eps 100 --duration 5

# Start the PyWarp engine daemon to process these logs
wparse daemon
```

## 🐳 Docker Support

PyWarp is fully containerized for seamless cloud deployment:

```bash
# Build the Docker image
docker build -t pywarp-engine .

# Run the container (mounting your local 'data' directory to see results)
docker run -v $(pwd)/data:/app/data pywarp-engine
```
